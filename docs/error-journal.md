# Error journal

## Format

- **Date** – YYYY-MM-DD  
- **Severity** – Low / Medium / High / Critical  
- **Summary** – One line  
- **Details** – Repro / logs  
- **Root cause** (if known)  
- **Status** – Open / In Progress / Fixed / Won’t Fix  
- **Resolution**
