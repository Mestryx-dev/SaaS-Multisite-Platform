# ADR-0000: Record architecture decisions

**Status**: Accepted  
**Date**: 2026-07-16

## Context

Mestryx Multisite Platform needs durable, reviewable technical decisions.

## Decision

Use Architecture Decision Records in `docs/adr/`, numbered, in English, with Status / Context / Decision / Consequences.

## Consequences

Agents and humans must propose or update an ADR for significant stack, tenancy, or billing choices.
